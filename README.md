# Асинхронное API и покрытие тестами

Учебное задание: написать тесты к API с использованием асинхронного программирования и метрик покрытия.

## Что внутри

- `app.py` — небольшое API на FastAPI: проверка живости, список заметок с фильтром по тегу, создание, чтение и удаление.
- `tests/test_api.py` — семь асинхронных тестов на httpx.AsyncClient и pytest-asyncio.
- `pytest.ini` — режим `asyncio_mode = auto`.
- `requirements.txt` — зависимости.

## Запуск

```
python3 -m pip install -r requirements.txt
python3 -m pytest -q --cov=app --cov-report=term-missing
```

## Результат

Семь тестов проходят, покрытие `app.py` сто процентов, непокрытых строк нет.

```
app.py      34      0   100%
TOTAL       34      0   100%
7 passed in 0.25s
```

## Что проверяют тесты

Здоровье сервиса. Создание заметки с тегами и последующее чтение. Фильтрация по тегу. Ошибка валидации при пустом заголовке. Запрос несуществующей заметки. Удаление и повторное удаление. Параллельная отправка пяти запросов через asyncio.gather, чтобы проверить, что идентификаторы не пересекаются.

## Почему покрытие сто процентов

Приложение маленькое, поэтому все ветки достижимы: есть и успешные сценарии, и обе ветки с ошибкой 404, и ветка валидации. Если бы в коде остались обработчики внешних сбоев, например таймаута базы, их пришлось бы покрывать отдельно через подмену зависимостей.
